# RoboIterate Product Definition

## Product Thesis

Robotics teams lose build seasons to slow custom-part iteration. A narrow tool that checks robot parts, generates local RFQs, and proves shorter iteration cycles can create value before becoming a broader hardware supply-chain platform.

## Customer Profile

Initial users:

- FTC/FRC students and mentors
- University robotics clubs
- Early robot startups

They usually have CAD skills, urgent deadlines, and local fabrication options, but weak procurement workflows.

## Workflow

1. Create a robotics project.
2. Upload an STL or STEP part revision.
3. Review extracted facts and DFM warnings.
4. Pick a suggested process or override it.
5. Select a supplier.
6. Generate a quote request.
7. Log response/build timing.
8. Use dashboard metrics as evidence of faster iteration.

## MVP Metrics

- Parts uploaded
- Findings caught per part
- Revisions per project
- Average time between revisions
- Quote requests generated
- Supplier response time, if entered
- Estimated days saved versus manual baseline
